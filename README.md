No GitHub, abra o arquivo e use **Download raw file**. Os [links diretos da página principal](https://github.com/gedielsonsaramento/S-Retorno.apk) iniciam o download.

Instale o APK sobre a edição TVBox anterior com o mesmo certificado, sem desinstalar. No Spresenter, instale o ZIP específico da Central. O ZIP de fontes é para desenvolvimento e contém os recursos de compilação desta entrega.

Android 6 utiliza HTML. NDI requer Android 7/API 24 ou superior, ARM e runtime compatíveis. A versão é candidata e ainda precisa de teste de imagem, som e fluidez nas boxes da igreja.
