# Downloads — S-Retorno 1.5.1 + Central 0.1.1

[Baixar o pacote com aplicativo, plugin e manual](https://github.com/gedielsonsaramento/S-Retorno.apk/raw/refs/heads/downloads-1.5.1/S-Retorno-1.5.1-Central-pacote.zip)

1. Extraia o ZIP e instale `S-Retorno-1.5.1.apk` na TV, box ou celular Android.
2. No S-Present, abra **Configurações → Plugins → Instalar (.zip/pasta)** e selecione `S-Retorno-Central-0.1.1.zip` extraído do pacote.
3. Na TV, abra **Engrenagem → Central de Retornos → Gerar código de pareamento**. No plugin, use **Vincular retorno** e informe o endereço e o código mostrados na TV.

O APK foi preservado exatamente como recebido. O [plugin também pode ser baixado separadamente](https://github.com/gedielsonsaramento/S-Retorno.apk/raw/refs/heads/downloads-1.5.1/S-Retorno-Central-0.1.1.zip). Consulte o [manual](MANUAL-DA-CENTRAL.md) e as [somas SHA-256 dos dois ZIPs](SHA256SUMS.txt).

Este pacote não inclui o código-fonte Android da 1.5.1. O [projeto completo 1.5.2](https://github.com/gedielsonsaramento/S-Retorno.apk/raw/refs/heads/downloads-1.5.2/S-Retorno-1.5.2-Projeto-Completo.zip) contém fontes e instaladores dessa outra versão; eles não correspondem ao APK 1.5.1.

Android 6: HTML. Android 7 ou superior: HTML e NDI, conforme aparelho e runtime. A validação física desta distribuição continua necessária.
